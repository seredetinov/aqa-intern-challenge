# Тестовое задание для AQA стажёра в компании Учи.ру - Середетинов Тимур

Привет! Ниже описаны внесённые изменения.

## Список изменений

### [Проведён рефакторинг Page Object `WidgetPage`](https://github.com/seredetinov/aqa-intern-challenge/commit/1067589)

- Удалён отдельный `enum WidgetPageSelectors`: селекторы теперь используются непосредственно в локаторах.
- Локаторы перенесены в приватные поля и инициализируются в конструкторе класса.
- Добавлены отдельные локаторы для:

  - плашки кук;
  - кнопки закрытия плашки кук;
  - кнопки открытия виджета;
  - тела виджета;
  - популярных статей;
  - кнопки «Написать нам»;
  - кнопки закрытия виджета;
  - обёртки виджета.

- Добавлены новые методы:

  - `goto()`;
  - `closeCookiesPopup()`;
  - `closeWidget()`;
  - `checkWidgetIsVisible()`;
  - `checkWidgetIsNotVisible()`;
  - `clickFirstPopularArticle()`;
  - `checkHeaderIsVisible()`.

- Удалены старые методы:

  - `wrapper()`;
  - `getPopularArticles()`;
  - `getTitle()`;
  - `getWidgetBody()`.

- Все методы теперь `async`.
- Для элементов с атрибутами `data-testid` или `role` теперь используются методы `getByTestId()` и `getByRole()`.
- Проверки видимости и заголовка перенесены в Page Object.

### [Проведён рефакторинг тестов](https://github.com/seredetinov/aqa-intern-challenge/commit/24b9706)

- Названия тестового класса и методов обновлены, чтобы они лучше отражали суть проверки.
- Все действия и проверки обёрнуты в `test.step()`, чтобы отчёты было удобнее читать.
- Открытие страницы и принятие кук вынесены в отдельные методы класса `WidgetPage`.
- Тест открытия виджета теперь использует готовую проверку его отображения из класса `WidgetPage`.
- Тест заголовка теперь:

  - использует готовые методы класса `WidgetPage` для клика по первой статье и проверки заголовка;
  - объявляет ожидаемый заголовок в отдельной переменной перед проверкой вместо хардкода.

### [Добавлен новый тест для проверки закрытия виджета](https://github.com/seredetinov/aqa-intern-challenge/commit/a3c1181)

Тест работает по следующему сценарию:

- открыть виджет;
- проверить видимость;
- закрыть виджет;
- проверить, что он больше не отображается.

### [Устранение нестабильности тестов](https://github.com/seredetinov/aqa-intern-challenge/commit/2ae85ec)

Хотел бы тут чуть подробнее расписать про логику этого изменения.

Изначально при прогоне тестов заметил, что они иногда флакуют - примерно в 3-4 запусках из 30 не появляется кнопка открытия виджета и тест падает. 
Сначала я попробовал добавить ретраи обновления страницы на такие случаи, но не помогло - за 3 релоада страницы ничего не менялось.
Оказалось, что проблема была в куках, а если точнее - в куке для АБ **ab_mainpage_redesign**. 
Тесты попадают в разные группы, и для некоторых групп этот виджет не загружается.
Соответственно, в качестве фикса теперь в `beforeEach` задаю нужную группу АБ-теста, чтобы виджет гарантированно был доступен.

### Изменения в конфигах

- [поднята версия **playwright**](https://github.com/seredetinov/aqa-intern-challenge/commit/ebbde68);
- [добавлена поддержка `data-test` в качестве `testIdAttribute` для метода `getByTestId()`](https://github.com/seredetinov/aqa-intern-challenge/commit/39e9cea).

## Подготовка к работе

Для начала работы убедитесь, что у вас установлены [Node.js версии 20 или новее и npm](https://nodejs.org/en/download).

Установите зависимости проекта, выполнив команду:

```shell
npm ci
```

## Запуск тестов

Запустите тесты с помощью команды:

```shell
npx playwright test
```

Запустите конкретный тест с помощью команды:

```shell
npx playwright test -g "Открытие виджета"
```

или

```shell
npx playwright test tests/widget.spec.ts:27
```
